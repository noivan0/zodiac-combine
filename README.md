# 애들아 다들 이거 합쳐봐 ㅈㄴ세짐

**Bright Brutalism** 버전 · 음력 정확한 띠 + 별자리 합체 생성기

## 스타일
- 밝은 배경 (#FFF8F0)
- 두꺼운 검정 테두리 + 하드 그림자 (브루탈리즘)
- Black Han Sans + Space Mono
- 형광 포인트 컬러 (핑크 / 노랑 / 라임 / 블루)

## 기능
- 음력(설날) 기준 정확한 띠 계산 (lunar-javascript)
- 12×12 = 144개 조합 전부 지원
- 조합마다 결정적(해시)으로 다른 재미 설명 + 브랜딩 문구
- 큰 이모지 캐릭터 + 텍스트 브랜딩

## 캐릭터 이미지에 대해
현재는 **이모지 합체 + 강한 텍스트 브랜딩**으로 144개 조합을 커버합니다.
144개 고유 AI 일러스트를 전부 생성·호스팅하면:
- 용량이 커짐
- GitHub Pages 로딩이 무거워짐
- 생성 시간·비용이 큼

원하면 인기 조합 10~20개만 샘플 이미지로 만들어 넣거나, 캐릭터 디자인 가이드를 따로 뽑을 수 있습니다.

## 배포
index.html 하나만 올리면 GitHub Pages에서 바로 동작합니다.
